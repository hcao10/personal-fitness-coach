# Cmine Fit 正式界面：Everyday Strength

沿用已确认的 Cmine Fit demo：白色与浅灰画布、自然训练场景、深绿色主操作、系统字体、大留白和安静的卡片层次。首页讲清楚产品价值；进入应用后突出当前任务和真实记录。

## 页面清单

| --- | --- | --- |

## 实现边界

- 主视觉与布局集中在 `app/components/home-experience.tsx`、`app/styles/design/experience.css`，由原主题入口引入。其余界面继续使用既有业务组件。
- 新文案进入类型检查覆盖的中英文消息表 `packages/i18n/src/messages/refresh.ts`；保留原有语言选择和服务端语言解析。
- 首页的训练与教练示意明确标注示意，不读写训练记录，不调用真实模型。
- 首页使用此前 demo 的生成图片，压缩为约 47 KB WebP；已有训练静物和动作媒体继续使用原素材及署名。
- 计划说明中的经验/器械/地点只调整显示名称，训练剂量、热量计算、安全阈值、AI 工具与提示词不变。
- OAuth、Cmine ID 配置、服务端认证、数据库迁移、支付和推送实现未在本次设计中改写。现有未提交的其他工作保留。
- 操作按钮保持单行；动作卡、问题建议和缺省媒体说明允许文字换行，保证小屏可读。

## 验证

- `npm run typecheck`、`npm run lint` 通过。
- `npm test` 通过：167 个审核动作素材校验、正式构建、216 项测试。
- 全量测试包含实际 HTTP/SDK/SQL 的教练草案和确认回归，以及访客、语言、安全规则、权限与接口检查。
- 浏览器使用正式构建、实际处理器和独立 SQLite 测试库。模型端使用本机协议夹具，不能视为外部真实模型质量验收，也未访问用户生产记录。
- 浏览器验证逐组保存与休息计时、疼痛反馈、教练拒绝/接受、今日变化与周计划隔离、首页场景切换与 FAQ、配套页面导航。
- 检查中修复了窄屏网格、建档步骤、动作长名称和无素材卡片溢出。手机和桌面使用同一套正式组件。

界面发布使用 scripts/release-ui.mjs；每次保存线上版本、健康状态和回滚点到 Git 忽略的 .wrangler/releases/。
