# @cmine-fit/coach-core

The stateless planning core used by Cmine Fit. It calculates BMR, TDEE,
calorie boundaries, macro targets, training frequency, exercise eligibility,
and a safe weekly rule-based plan without requiring a database, account,
network call, or hosted service.

The package is the boundary for the self-hosted edition. Hosted identity,
history, progress, operations, billing, rewards, and long-term coaching stay
outside this package.
